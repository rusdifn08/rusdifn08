### Tentang Saya

Fullstack Developer dan AI/IoT Engineer yang berfokus pada pengembangan aplikasi lintas platform (Web, Mobile, Desktop), sistem *Computer Vision* waktu nyata, serta integrasi perangkat keras berbasis mikrokontroler. Berpengalaman merancang arsitektur *end-to-end* mulai dari *firmware* tingkat rendah hingga antarmuka pengguna modern dan manajemen infrastruktur *self-hosted*.

- **Web & Mobile Development:** React, Next.js, TypeScript, Flutter, Tauri, Rust (Axum), Go.
- **AI & Computer Vision:** Object Detection (YOLO), OpenCV, Python, Edge AI Inference.
- **IoT & Embedded Systems:** ESP32, C/C++, Rust (`no_std`), MQTT, RTOS, Sensor Telemetry.
- **DevOps & Database:** Docker, PostgreSQL, MySQL, MongoDB, Self-Hosted Infrastructure.
